# EXP-004 — Tool-contract matrix

**Hypothesis**  
How much recovery behavior is determined by tool guarantees rather than the harness?

**Setup**  
40 paired trials/method/contract across readback-only, idempotency-only, both, neither.

**Result**  
With idempotency, Retry/Verify/Rewind/Resutura all reached 100%. With readback only, Verify and Resutura reached 100%; Retry/Rewind duplicated. With neither, Verify and Resutura safe-aborted.

**Interpretation**  
The tool contract can dominate the recovery strategy; a runtime should not claim credit for guarantees supplied by the tool.

**Next decision**  
Make tool capabilities first-class inputs and report contract-conditioned results.
