# EXP-007 — Counterfactual recovery analysis boundary

**Hypothesis**  
Can forked-state counterfactual outcomes be used to select the online repair?

**Setup**  
Early simulator implementation executed candidate repairs on forked state and used those outcomes during selection.

**Result**  
Methodological audit found this leaks oracle information unavailable to a real online agent.

**Interpretation**  
Counterfactual replay is useful for diagnosis, but using realized fork outcomes for online policy selection overstates capability.

**Next decision**  
Set used_for_policy_selection=false; online selection only sees observations + declared tool contract.
