# EXP-001 — Baseline recovery kernel

**Hypothesis**  
Can explicit expected-state verification plus structured recovery beat a plain agent and blind retry in a deterministic long-horizon workflow?

**Setup**  
120 paired simulator tasks; Base, Blind Retry, Resutura.

**Result**  
Base 26.7%, Blind Retry 45.0%, Resutura 100% task success in the deterministic pilot.

**Interpretation**  
The mechanism was worth pursuing, but the result was only simulator evidence and too easy to treat as a general capability claim.

**Next decision**  
Move from generic recovery to effect-semantics cases where local rewind and retry can be demonstrably wrong.
