# EXP-010 — Provider-neutral policy boundary

**Hypothesis**  
Can the runtime consume actions from an external policy interface without conflating replay with model-backed evidence?

**Setup**  
Recorded policy replay, 20 deterministic trials, provider-neutral JSON bridge.

**Result**  
20/20 replay trials complete successfully; artifact is explicitly model_backed=false.

**Interpretation**  
Separating policy from recovery runtime is necessary for later model experiments, but replay is not model evidence.

**Next decision**  
Preserve the interface and gate all model-backed claims on a genuine external model run.
