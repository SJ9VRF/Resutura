# EXP-009 — Formal component ablations

**Hypothesis**  
Which components are actually necessary inside the deterministic testbed?

**Setup**  
40 paired seeds/cell; remove compensation, contract awareness, or effect ownership.

**Result**  
−compensation: 0% on compensable misdirection; −contract awareness: 0% on ambiguous commit with 100% duplicates; −ownership: 0% on concurrent-valid-change case.

**Interpretation**  
Each component is tied to a distinct failure class rather than a generic “more machinery helps” story.

**Next decision**  
Keep ablations as claim-specific evidence, not as generic performance improvement.
