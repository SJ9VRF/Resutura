# EXP-011 — Byte-level reproducibility

**Hypothesis**  
Can the same code, seed, and config produce identical evidence bytes, not just similar metrics?

**Setup**  
Deterministic run/failure IDs, logical timestamps, deterministic gzip mtime, repeated signature runs.

**Result**  
Canonical signature outputs and dataset exports are byte-stable under repeated same-code/same-seed execution.

**Interpretation**  
Evidence provenance is easier to audit when raw artifacts are stable enough to hash.

**Next decision**  
Make deterministic artifact hashes part of the release contract and claim-evidence map.
