# EXP-006 — Non-compensatable effects

**Hypothesis**  
Should recovery attempt to “win” when an external effect has no safe inverse?

**Setup**

**Interpretation**  
A negative result is the correct result when repair is impossible. Optimizing only for completion would reward unsafe behavior.
