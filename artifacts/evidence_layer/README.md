# Evidence Layer

The polished homepage answers *what Resutura is*. This layer answers *how the project actually got there*. It deliberately preserves failed assumptions, evaluator bugs, awkward baseline wins, design pivots, raw runs, and decisions that weakened the marketing story but strengthened the research.

## Start here

1. [Experiment journal](../experiment_logs/README.md) — 12 documented experiments / maturation steps
2. [What didn't work](FAILED_EXPERIMENTS.md) — 12 documented failures, bugs, or framing reversals
3. [Decision log](DECISION_LOG.md) — 10 major design decisions with alternatives and trade-offs
4. [Real eval tables](REAL_EVAL_TABLES.md) — executed numbers only
5. [Unexpected findings](UNEXPECTED_FINDINGS.md) — results that changed the project
6. [Git history note](../git_history/README.md) — authentic history policy; no backfilled fake commits
7. [Raw artifact index](RAW_ARTIFACTS.md) — runs, configs, failures, ablations, qualitative cases
